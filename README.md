AI Agent RAG Workflow (미래AI기술.pdf)
n8n을 활용한 RAG(Retrieval-Augmented Generation) 파이프라인 구현 과제입니다. Google Drive의 PDF 문서를 벡터 DB에 적재하고, AI 챗봇을 통해 정확한 문서 기반 질의응답을 수행합니다.

Quick Start
Load Data: Execute Workflow 버튼을 눌러 미래AI기술.pdf 파일을 다운로드 및 추출한 뒤 벡터 DB에 적재합니다.

Retriever Flow: 챗봇 인터페이스를 통해 적재된 문서 내용에 대해 질문합니다.

Tech Stack
Workflow Automation: n8n

Cloud Storage: Google Drive (미래AI기술.pdf)

AI & Embeddings: Google Gemini
